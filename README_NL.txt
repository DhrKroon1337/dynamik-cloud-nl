Snelstart (NL):
1) Zet map op GitHub (private) met de git-commando's.
2) Render.com: New → Web Service → kies repo → zet OPENAI_API_KEY (+ SHARED_SECRET) → Deploy.
3) Noteer je URL en zet die in mobile-expo-stream-nl/app/api.js als BASE_URL.
4) Expo Go: cd mobile-expo-stream-nl && npm install && npm run start → QR scannen.
5) APK: eas login → eas build -p android --profile preview.
Knoppen: Spec (specificaties), Code (startercode), Visual (diagram/HTML).
